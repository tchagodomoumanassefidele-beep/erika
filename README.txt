ERIKA TECHNOLOGY — MAQUETTE DE SITE WEB
========================================

Fichiers
- index.html      : page d'accueil
- services.html   : détail des domaines d'activité
- apropos.html    : présentation et valeurs
- contact.html    : coordonnées et formulaire WhatsApp
- style.css       : design responsive et animations
- script.js       : menu mobile, année automatique, formulaire WhatsApp

Aperçu
Ouvrez index.html dans un navigateur. Une connexion Internet est recommandée pour les photos et les polices distantes.

Fonctionnement du formulaire
Le formulaire de contact prépare un message puis ouvre WhatsApp vers le numéro +228 70 33 71 19. Il ne transmet pas de données à un serveur.

À vérifier avant publication
- Confirmer les numéros, l'adresse et les horaires affichés.
- Remplacer les photos d'illustration par les photos officielles de l'entreprise si disponibles.
- Ajouter, si nécessaire, une adresse e-mail officielle et les liens des réseaux sociaux.
- Le site est une maquette de présentation : les prestations exactes et les horaires doivent être validés par l'entreprise.

Mise en ligne
Les fichiers HTML, CSS et JavaScript sont tous dans le même dossier. Vous pouvez les publier sur GitHub Pages ou un hébergement web classique.
